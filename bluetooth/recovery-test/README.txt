PhoneDesk 程序故障復原測試 1.0

這是能直接執行的 Windows x64 測試工具，不需要 Python。
它測試獨立看門狗處理程序閃退／停止回應，不是實體藍牙控制權還原測試。

1. 完整解壓縮到可寫入的資料夾，執行 PhoneDeskRecoveryTest.exe。不需要系統管理員權限。
2. 按「測試閃退」，等待通過。
3. 按「測試無回應」，等待通過。
4. 兩次完成後確認滑鼠仍能移動與點擊，把畫面與 logs/current.log 傳回。
5. 如果失敗或超過 30 秒，傳回 logs 與 reports 資料夾，不要繼續 USB 接管。

工具只啟動自己建立的測試子程序；獨立看門狗最多執行約 12 秒，必要時終止自己的子程序。
關閉主視窗不會立即取消已開始的看門狗，但它應在約 12 秒內自行結束並留下結果。
不呼叫 SendInput／BlockInput、不更換驅動、不拔除或停用介面、不連藍牙、不刪配對、不錄音、不上傳。
日誌位於 logs/current.log，同日累加、跨日寫入覆蓋。

重要限制：
- 測試期間 Windows 從未失去滑鼠控制，所以通過不能解讀為「WinUSB 接管後已能恢復鍵鼠」。
- 真正接管後還需要原驅動備份、獨立於實驗程式的還原機制，以及配對金鑰／重新配對的復原驗證。
- 還原驅動不一定能還原裝置上的配對金鑰；若金鑰已改變，仍可能需要實體操作重新配對。
- 目前使用者沒有有線滑鼠，因此本工具不啟動任何實體接管測試，也不代表已可放心換成 WinUSB。

建置原始碼包含在 source/。使用 Build.ps1；ZIP 內含 DailyLog.cs，從 repo 建置則共用相鄰 bluetooth/source/DailyLog.cs。
