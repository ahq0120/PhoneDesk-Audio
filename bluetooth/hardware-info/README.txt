電腦／主機板與藍牙介面資料收集 v1.0

1. 完整解壓縮。
2. 雙擊 Run-Hardware.cmd，不需要 Python 或系統管理員權限。
3. 等待 Completed，將 reports 裡最新產生的 ZIP 傳回。
4. SUMMARY.txt 是可直接閱讀的摘要，hardware.json 是結構化資料。

收集：整機品牌型號、主機板廠牌型號版本、Windows 版本、USB／PCI 藍牙介面名稱、
USB VID/PID/REV、驅動廠商／版本／日期／INF 與裝置狀態。
各區段以獨立程序查詢，18 秒未完成就終止該查詢並標記 Timeout，接著繼續其他區段。
不安裝、不改驅動、不停用裝置、不斷開藍牙、不錄音、不上傳。
不要求主機板／整機序號、裝置唯一實例 ID、配對裝置清單或藍牙位址。

重要：晶片商與 VID/PID 不一定代表藍牙棒的零售品牌、商品型號或包裝上的硬體版本。
USB REV 也不能直接當成 PCB／商品硬體版本。若無法辨認，仍需拍本體或包裝，不能靠腳本猜測。
傳送前可查看 SUMMARY.txt；型號與廠商文字由設備廠商提供。
